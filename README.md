# Metodi Quantitativi per la Finanza (MQF)

Materiali didattici del corso di **Metodi Quantitativi per la Finanza**, dedicato alla modellizzazione dell'incertezza, alla misurazione del rischio e ai problemi decisionali in ambito finanziario.

Il repository raccoglie:

- il [manuale del corso](01_Manuale/);
- le [slide delle lezioni](02_Slides/);
- esempi e applicazioni in [Python](04_Codice/);
- il [piano del progetto e le linee guida](00_MasterPlan/).

Il percorso integra teoria della probabilità, processi stocastici, catene di Markov, misure di rischio e ottimizzazione, affiancando alla trattazione matematica esempi finanziari e attività computazionali.
